## 🎯 About The Game

Catch The Mouse is a responsive mini-game built with pure Vanilla JavaScript, modern HTML5, and CSS3. Test your speed and precision by catching as many mice as possible before the timer runs out!

### 🌟 Key Features
- ⚡ Dynamic Gameplay: Randomly emerging mice requiring fast reaction times.
- ⏱️ Timer & Score System: Real-time tracking of remaining time, caught mice, and highest score.
- 📱 Fully Responsive Layout: Seamless experience across Desktop, Tablet, and Mobile devices.
- 🎨 Modern UI: Clean, aesthetically pleasing green-themed visual interface.
- 🔊 Interactive Feedback: Instant visual cues upon clicking.

## 🕹️ Game Rules & Missions

| Mission | Objective |
| :--- | :--- |
| 🎯 Target | Click on the mouse as soon as it pops out of the hole. |
| 🏆 Win Condition | Catch 10 mice to achieve victory! |
| ❤️ Life System | One wrong click = Lose 1 Heart. |
| ⏳ Timer Challenge | Beat the countdown before the timer reaches 0. |
